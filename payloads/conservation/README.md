## Conservation Payload

This payload contains EcoSentinel/Naturaii X-origin node logic refactored for conservation and anti-poaching workflows.

Dual-use mapping:
- Primary: wildlife protection and protected-area monitoring.
- Secondary: detection, tracking, and risk triage patterns reusable for BORAP 04 analytics in non-kinetic defensive workflows.

Contained node copies:
- `conservation_fusion_node.py`
- `conservation_detection_node.py`
- `conservation_prediction_node.py`
- `conservation_triage_node.py`
- `conservation_autonomy_node.py`
- `conservation_dashboard_bridge.py`
